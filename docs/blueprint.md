# **App Name**: Flut Digital Hub

## Core Features:

- Homepage Hero Animation: Dynamic Three.js background wave animation for the homepage hero section to create an engaging visual experience.
- Service Pages: Dedicated pages for each service (Web, Branding, 3D/AR, AI, Social, Training) providing detailed information and examples.
- Reference Showcase: Interactive reference section with project showcases, including individual case pages and a slider for featured projects.
- Blog Platform: Integrated blog with article overview and individual article pages using MDX for content creation and management.
- Contact Form with Scheduling: Contact form integrated with react-hook-form and zod, including a placeholder for a scheduling link to streamline inquiries.
- AI-Powered Chatbot: AI chatbot tool providing assistance and information to visitors, enhancing user engagement, powered by generative AI, available through API endpoint stub.
- Technology Stack Display: Visually appealing display of the tech stack used by Flut Digital, incorporating logos and badges for each technology.

## Style Guidelines:

- Background: Deep blue (#0C1018) to create a sophisticated and modern base.
- Background 2: Darker shade (#101622) for depth and layering effects.
- Foreground: White (#ECF3FF) for high contrast and readability against the dark backgrounds.
- Primary: Blue (#1C91FF) to represent trustworthiness and innovation; the primary color brings focus to key interactive elements.
- Accent: Turquoise (#40CFFF) as a vibrant highlight color, complementing the primary blue.
- Font: 'Inter' (sans-serif) for a clean, modern, and highly readable user experience; suits both headlines and body text.
- Use 'lucide-react' icons: Consistent, simple, and modern icons to enhance usability and visual appeal.
- Implement a glass-style effect using blur, a white border, and shadow to highlight key interface elements, creating depth and focus.
- Subtle fade-in effects and smooth page transitions using 'framer-motion' to enhance user experience and add a modern touch.
